# Decision Log — PRD: API Rate Limiting

## Session: 2026-05-19

---

### DL-1 — Scope: all endpoints, global middleware
**Decision:** Rate limiting applied globally to all routes via FastAPI middleware, not per-endpoint.
**Rationale:** Analyst elicitation received no answers. Simplest defensible default for an internal service; per-endpoint tiers deferred as OQ-1.
**Status:** Assumed — open for PM/stakeholder override.

### DL-2 — Subject of limit: X-User-Id first, IP fallback
**Decision:** Limits enforced per `X-User-Id` header when present; per client IP when not.
**Rationale:** The service's existing auth primitive is `X-User-Id`. Using it preserves consistency. IP fallback handles unauthenticated probes.
**Status:** Assumed — see OQ-2.

### DL-3 — Default limit: 60 requests/minute per subject
**Decision:** 60 req/min as the initial default, matching a 1 req/sec sustained rate.
**Rationale:** No stakeholder input received. 60/min is a widely understood default for internal APIs; low enough to deter abuse, high enough not to break typical clients.
**Status:** Assumed — must be confirmed before implementation (OQ-3).

### DL-4 — Algorithm: fixed window, in-process
**Decision:** Fixed window counter (no sliding window, no token bucket). State held in-process (Python dict + threading.Lock).
**Rationale:** SQLite single-instance deployment makes an external store (Redis) out of scope. Fixed window is stdlib-only, simplest to test. Burst artefacts acknowledged and deferred.
**Status:** Assumed — see OQ-4 re horizontal scaling.

### DL-5 — Response: HTTP 429 + Retry-After header
**Decision:** Return `429 Too Many Requests` with `Retry-After: <seconds>` and a JSON body.
**Rationale:** RFC 6585 standard. Allows well-behaved clients to back off without polling.
**Status:** Decided — no open question.

### DL-6 — No new third-party dependencies
**Decision:** Implementation must use Python stdlib only (no `slowapi`, no `limits`).
**Rationale:** CLAUDE.md project guardrail: "No new third-party dependencies without a clear reason. Stdlib first."
**Status:** Decided — firm constraint from project rules.
